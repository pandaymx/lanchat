# ADR-010: i18n 用 Translator 注入 + flat key + lowercase locale + JSON embed.FS

- 状态：✅ 已采纳
- 日期：2026-09-05（M3.10）
- 关联：AGENTS.md §13 国际化

## 背景

TUI 需要中英文 UI。`pkg/` 不得 import `internal/`（gomobile bind 时 internal 不可达），而 i18n bundle 放 `internal/` 最合理；且 Go 1.22+ vet 会把 `(string, ...any)` 当 print-like 误报。

## 决策

- `pkg/tui` 内置 `Translator interface { T(key string) string }`，**注入而非 import**；`cmd/tui` 启动期调 `i18n.MustLoadEmbedded` 后把 `bundle.ForLocale(locale)` 注入 Config
- bundle 用 **JSON + embed.FS**，零 codegen、零新第三方依赖
- key 命名 flat：`domain.area.item`（如 `tui.status.online`），不分 namespace
- locale 一律 **lowercase**（文件名 / map key / DetectLocale 输出三处一致），否则 fallback 链静默吞错误
- fallback 链：locale → `en` → key 字面值
- `FormatArgs []any` 替代 `...any`，绕开 vet print-like 误报

## 备选方案

| 方案 | 否决理由 |
|---|---|
| pkg/tui 直接 import internal/i18n | 破 Go 模块边界，gomobile bind 不可达 |
| gettext / 第三方 i18n 库 | 引入依赖，违背零 transitive 依赖策略 |

## 落地位置

- `pkg/tui/translator.go`（Translator + nopTranslator + enDefaults）
- `internal/i18n/{i18n,embed}.go` + `bundles/{en,zh-cn}.json`
- `cmd/tui`：`-lang` / `-lang-list` flag + DetectLocale（commit 6fa8af4 / 96a60d6 / f94ab72）

## 验证

- `internal/i18n` 17 测试（Load/T/Tf/ForLocale/DetectLocale），覆盖率 97.4%
- `pkg/tui` fakeTranslator 14 key 全被命中
- `cmd/tui TestBundlesEndToEnd_ZHCN`：完整链路返回「在线」
- 真机：`-lang zh-cn` / `-lang en` 双窗口对照
