# ADR-012: Web 端 thin proxy，不重复 hub 调度

- 状态：✅ 已采纳
- 日期：2026-09-05（M4.1 拍板）
- 关联：ADR-002 / ADR-011

## 背景

M4 Web server 的角色选择：是内嵌一套 hub 逻辑，还是只做桥接。若内嵌 `hubstate.Router`，hub 的调度/广播/游标逻辑要维护两份。

## 决策

- `internal/webui` 只做 **thin proxy**：HTTP ↔ `pkg/client.Client` 桥接，不做 hub-like 调度
- 复用 `pkg/client.Client` 接口（fake Hub + 真 Hub 同源，ADR-002 的产物）
- `Session` 由 `DialClient` 装配：`transport.Dial → memory store → event bus → client.New → Connect`

## 备选方案

| 方案 | 否决理由 |
|---|---|
| Web server 内嵌 hubstate.Router | 两份调度逻辑，维护与一致性成本翻倍 |

## 落地位置

- `internal/webui/session.go`（DialClient 装配 + 释放顺序 cli.Close → store.Close）
- `internal/webui/handler.go`（注入窄接口 `Client`：SendMessage/Subscribe/History/Done）
- `cmd/web/main.go`（`-hub-url` 必填，ws transport 拨号 5s 超时）

## 验证

- `internal/webui` 编译断言 `*client.Client` 满足窄接口
- M4.3 E2E 双 web 实例经 thin proxy 互发消息闭环
